# Convergence matrices

## 1. Affinity clustering

1. Print all ideas by id and one-line text.
2. Pick the first idea; put it in cluster 1. For each next idea, join the cluster whose underlying move it shares, or start a new cluster.
3. Name each cluster with a verb phrase for the move.
4. Merge clusters of fewer than 2 ideas into an `orphans` group unless they are distinct.
5. Record per cluster: id list, one-line summary, the strongest representative.

## 2. Impact versus effort grid

Place each candidate by impact (rows) and effort (columns):

| | Low effort | High effort |
| --- | --- | --- |
| High impact | do first (quick win) | plan carefully (big bet) |
| Low impact | fill-in | drop |

Use the 1 to 5 scores from the rubric: impact 4 or more is high; effort score 4 or more (inverted, so low effort) is low effort.

## 3. Weighted matrix

Rows are ideas, columns are criteria with their weights, final column the weighted total and the unweighted average. Sort by weighted total. Flag rows with a must-have fail as `OUT`.

## 4. Pairwise duel

For the top five when totals are within 10 percent: compare every pair on "which would you rather have if you could only pick one?" Count wins. Use only to break near-ties; report the result with the matrix, not instead of it.

## 5. Risk and reversibility screen

| | Easily reversed | Hard to reverse |
| --- | --- | --- |
| Low risk | go | go with a checkpoint |
| High risk | pilot first | needs `lit-crucible` before any plan |

Anything in the bottom-right cell triggers the offer of `lit-crucible` in Phase 5.

## 6. Shortlist composition check

Before confirming: at least one safe option; at least one that differs in kind; no two entries share the same underlying move; each has a named first step. If two shortlisted ideas share a move, swap one for the best idea from a different cluster.
