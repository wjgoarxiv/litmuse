## Free listing

Write every answer that comes to mind for the chosen how-might-we, one line each, no ordering. First five ideas are usually the obvious ones; the target is past them. Rule: if an idea feels too small, silly or already known, list it anyway and tag it `[free]`.

## Selection by symptom

| Symptom on the board | Next technique |
| --- | --- |
| All ideas modify the current thing | analogy, assumption reversal, constraint flips |
| All ideas are big and risky | SCAMPER:eliminate and SCAMPER:reverse, constraint flips (smaller), crazy eights |
| Ideas feel generic | persona lenses, random stimulus |
| One dimension dominates | morphological box |
| User is silent or terse | crazy eights, worst-idea inversion |
| Stakeholders disagree | role storming, six hats |
| The frame itself feels off | go back to techniques-reframe.md |

## Rotation rule

Never use the same technique in two consecutive rounds. In a Deep session, use at least one technique from each card file.
