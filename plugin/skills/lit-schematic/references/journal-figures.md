# Journal figures

Column widths: 85 mm single, 120 mm intermediate, 178 mm double. Panels read (a), (b) from top
left. Type at 7 pt with a 6 pt floor. Latin text uses Arial embedded as text in the SVG and
PDF. Hangul labels use the Pretendard copy shipped with `lit-diagram-drawer` assets.

Stream colours come from the colour-vision-safe set with a key on the figure. Colour supports
the labels; labels carry the meaning in text. Keep the title out of the art; the caption owns
it.

Panels: 2D canvas panels for schematics and flows, 3D iso panels for rigs. Each panel earns
its place: one message per panel, shared scale noted where panels compare.

Export: SVG and PDF stay vector. PNG renders at 600 dpi for review. Chrome embeds Hangul as
vector-safe glyphs; say so in the reply when a venue checker flags font embedding, and ship
the PDF alongside the SVG.

Checklist before delivery: column width exact, type sizes at floor or above, key present,
caption parts named in the art, invented values labelled in the reply.
