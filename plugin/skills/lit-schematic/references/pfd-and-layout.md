# PFD, BFD, and equipment layout

BFD: blocks for units with named streams between them, one-line stream labels, major
utilities in. Use it for scoping and early reviews.

PFD: major equipment with stream numbers on every line and a stream table (number, from, to,
fluid, phase, key conditions). Instruments appear where a control loop defines the process;
full instrumentation waits for the P&ID.

Stream tables sit below the drawing or on a facing sheet, numbered to match the art. Every
number on the drawing comes from the process truth; example builds label invented values in
the reply.

Equipment layout: plan view on a scaled grid with equipment footprints, maintenance clearances,
pipe-rack lanes, access aisles, and north arrow. Gravity notes (pumps below suction, knockout
drums ahead of compressors) carry over from the P&ID rules.

Layout checks: footprints clear of each other, rack lanes continuous, relief headers rising
toward the flare or scrubber, drains falling toward collection. Open plot questions (a rack
lane awaiting a destination, a clearance tweak) go in the reply beside the files.
